Ejercicio 3.2: Autoevaluación

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué

  • a) Cualquier tipo input particular de formarto de HTML5 debe desplegarse de manera idéntica en todos los navegadores compatibles con HTML5. ==> Falso. El despliegue de los tipos input puede varias de un navegador a otro.

  • b) Cuando se coloca el enfoque en el campo de texto (es decir, si el cursos está en el campo de texto), se envía el texto del atributo placeholder al servidor. ==> Falso. Cuando se coloca el enfoque en el campo de texto, el texto de placeholder desaparece. "No se envía" cuando el usuario hace clic en el botón Enviar (a menos que el usuario escriba el mismo texto).

  • c) No es necesario incluir el atributo autofocus en sus formularios. ==> Verdadero

  • d) Los nuevos tipos input de HTML5 tienen validación automática del lado del cliente, con lo cual se elimina la necesidad de agregar secuencias de comandos (scripts) complicadas a sus formularios para validar la entrada del usuario y se reduce la cantidad de datos inv´lidos que se envían. ==> Verdadero

  • e) El tipo input range se valida automáticamente de manera intrínseca cuando el navegador lo despliega como un control deslizante, ya que el usuario no puede mover el control fuera de los límites del valor mínimo o máximo. ==> Verdadero

  • f) HTML5 cuenta con validación automática para el tipo input tel. ==> Falso. La longitud y el formato de los números telefónicos varía de manera considerable con base en la ubicación, por lo que la validación se vuelve bastante compleja, así que HTML5 no cuenta con validación automática para el tipo input tel. Para asegurar que el usuario introduzca el número en un formato apropiado usamos el atributo pattern.

  • g) Si el usuario introduce un URL con un formato inapropiado en un tipo input url, no se validará. HTML5 no valida si el URL introducido existe en realidad. ==> Verdadero

  • h) El elemento nav muestra un menú desplegable de hipervínculos. ==> Falso. El elemento nav agrupa vínculos de navegación.

  • i) El elemento header puede usarse sólo una vez en una pagina. ==> Falso. El elemento header puede usarse varias veces en una página y a menudo incluye encabezados de HTML(<h1> a <h6>)

  • j) Los elementos nav puede anidarse en un elemento aside. ==> Verdadero

  • k) Podemos usar el elemento brk para evitar dividir palabras en lugares incorrectos. ==> Falso. Puede usar el elemento wbr para evitar dividir las palabras en lugares incorrectos.
