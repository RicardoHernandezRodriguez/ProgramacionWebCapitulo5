Ejercicio 2.1: Autoevaluación

Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué

  1. a) Una lista ordenada no puede anidarse dentro de una lista desordenada ==> falso, si se pueden anidar y viceversa

  2. b) El elemento br representa un salto de linea ==> verdadero

  3. c) Los hipervinculos se denotan mediante elementos link ==> falso, se denotan mediante el elemento <a>

  4. d) La anchura de todas las celdas de datos en una tabla debe ser igual ==> falso, se puede declarar la anchura de cualquier columna

  5. e) Estamos limitados a un máximo de cinco vínculos internos por pagina ==> falso, se pueden usar cuantos se necesiten
